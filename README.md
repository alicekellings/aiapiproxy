# AI API Proxy

GitHub Pages 博客草稿，用于沉淀中文长尾 SEO 内容。

当前推荐仓库名：

- `aiapiproxy`

发布地址：

- `https://alicekellings.github.io/aiapiproxy/`

说明：

- `https://aiapiproxy.github.io/` 这种根地址必须对应 GitHub 用户或组织名 `aiapiproxy`。
- 如果以后拿到 `aiapiproxy` 用户或组织，再把本仓库迁移为 `aiapiproxy/aiapiproxy.github.io`，并把 `_config.yml` 的 `baseurl` 改回空字符串。
